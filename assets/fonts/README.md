# Fontes do relatório PDF

Noto Sans Regular e Bold, provenientes do [repositório oficial Noto Fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans), sob a licença SIL Open Font License 1.1 incluída em `OFL.txt`.

As fontes são servidas pelo próprio aplicativo e incorporadas ao PDF para preservar acentos e permitir o uso sem conexão após o primeiro carregamento.
